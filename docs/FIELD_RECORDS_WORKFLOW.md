# 现场照片收录与发布流程

每次收到新的“山中萨满”涂鸦现场照片，都按以下流程更新 `field-records.html` 并发布到 GitHub Pages。

## 1. 读取与排序

- 从原图读取 `DateTimeOriginal`、GPS 和海拔；不使用聊天上传时间代替拍摄时间。
- 时间统一转换为 `Asia/Shanghai`，按拍摄时间升序排列。
- 沿用三位编号：`001`、`002`、`003`……；网页不显示原始文件名。

## 2. 照片与地图

- 原图保留在本地现场档案；网页使用适合浏览的 JPEG 预览。
- EXIF GPS 为 WGS-84；生成百度地图前转换为 BD-09，避免中国地图坐标偏移。
- 每张地图固定为 `900 × 900 px`、`zoom=18`，编号直接标在地图坐标旁。
- 地图卡片点击后打开百度地图标注页，同时保留 Apple 地图辅助链接。

## 3. 页面更新

- 每条记录保持“左侧照片与拍摄时间、右侧地图”的桌面结构。
- 手机端保持照片、时间、地图的纵向顺序。
- 同步更新页头记录总数和首页入口中的 `FIELD RECORDS · NNN`。

## 4. 验证与发布

- 通过本地 HTTP 预览检查桌面和手机布局。
- 检查所有照片、地图、字体和链接均存在，确认页面返回 HTTP 200。
- 只提交本次记录需要的文件，保留无关的本地改动。
- 推送 `main` 后检查 GitHub Pages 工作流；发布地址为：
  `https://zilazer.github.io/mountain-shaman/field-records.html`
